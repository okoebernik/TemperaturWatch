Firmware update

The app firmware and web UI are updated independently. The app firmware is written to the inactive OTA slot and restarts automatically after a successful write; if the new firmware doesn't boot cleanly, the bootloader automatically rolls back to the previous one.

Time (NTP)

–

Synchronizes the device clock via NTP and drives the clock in the status bar. Takes effect immediately, no restart needed.

POSIX TZ syntax, e.g. "CET-1CEST,M3.5.0,M10.5.0/3".

Access

Protects the web UI and REST API with a password (HTTP Basic Auth). Takes effect immediately, no restart needed.

Guides for the REST API, MQTT, and PRTG – also available offline on the device.
